# External HDE density injection for single-pair inference

## Goal

Add a new, separate single-pair script that consumes a precomputed fog map
generated by the independent HDE verification project, while retaining every
subsystem and every weight from `Teacher_Train/source_best.pt` for routing and
dehazing.

## Scope

This is inference-only. The HDE verification project and the main dehazing
project stay independent: neither project imports the other's model code or
loads the other's checkpoint. Existing files, including `test_single_pair.py`,
remain unchanged; the feature is implemented in a new script.

## Data flow

1. Run the independent HDE verification project first. It saves a raw
   transmission map `T` for the RGB--TIR pair.
2. Load the main fog-routed checkpoint as today.
3. When an optional precomputed-map path is supplied, load that single-channel
   image only. It must already have the RGB image's spatial size; the main
   script does not import or execute the verification HDE project.
4. Convert `T` to the main model's
   density convention: `D = 1 - T`.
5. Create the main model context normally, preserving its existing
   `tir_structure_pyramid` and encoder features. Replace only
   `density_map` with `D`, then recompute route logits, soft route, and
   straight-through hard route through the loaded main-model router.
6. Decode with the unchanged `decode_with_route` method.

## Interface

The new `test_single_pair_external_hde.py` script accepts a required
`--external_transmission_map` path. The provided map must be a finite
single-channel PNG/TIFF at the RGB image's resolution.

The script saves:

- the raw external transmission map `T`;
- the injected main-semantic density map `D`;
- the existing dehazed image, density map, soft/hard route, and boundary map.

It also prints map quantiles and the fraction of hard-completion pixels.

## Safety and validation

- The main code treats the external map as image data only. It has no import
  path, runtime dependency, or checkpoint dependency on the HDE verification
  project.
- The transmission-to-density inversion is mandatory. Omitting it would
  reverse the route semantics.
- Test the default path first to establish an unchanged baseline, then test
  injection on `FLIR_04884`.
- Confirm that the saved injected density equals `1 - T` up to resize and
  8-bit image quantization; confirm original-resolution output sizes; report
  route statistics before and after injection.

## Expected limitation

This isolates density-map quality but does not retrain the collapsed router.
Consequently, the injected map may improve density diagnostics without
producing hard-completion pixels or a large dehazing change. That outcome
identifies the router, rather than the HDE map, as the next bottleneck.
