## 2. 已经确定的最终方法方案

### 2.1 HDE 与雾浓度路由

用户已有 HDE，输入 RGB 与 TIR，利用 TIR–RGB 的结构差异估计连续雾浓度图 `M`。HDE 包含：TIR CDC/ADC/RDC 差分结构编码、TIR 引导的可变形卷积、可见/TIR 多尺度结构差异注意力。该模块应保留，后续只按新总架构调整其输出接口（至少要可复用 TIR 结构特征）。

路由不再由独立掩码网络或人工浓度阈值产生，而是：

`M -> G_phi -> r_soft in [0,1]`

其中 `G_phi` 是**可学习的单调不减浓度—失效度校准器**。`r_soft` 接近 0 表示融合区，接近 1 表示补全区。训练前期连续，后期通过温度退火、直通式硬二值化和二值化损失趋近明确的 0/1 路由。`0.5` 只是概率二值化分界，不是雾浓度阈值。

单调约束非常重要：若 `M(B) > M(A)`，则必须有 `r(B) >= r(A)`。这保证即使某像素 B 当轮没有被效用监督采样，只要其预测雾浓度更高，也不会比低浓度 A 更倾向融合。

### 2.2 三流特征处理（不是输出图拼接）

在每个特征尺度上：

- **融合流**：处理低失效度区域。RGB 外观特征保存颜色、材质、亮暗和可用纹理；TIR 只提供轮廓、边缘、几何结构。TIR 结构作为 Query/偏移引导，RGB 外观特征作为 Key/Value，执行**TIR 结构引导的可变形 RGB 外观采样**。其目的不是处理配准（数据本身已配准），而是为每条可靠 TIR 结构从 RGB 邻域找到可用于渲染的颜色、材质和纹理。生成的是 RGB 域结构修正，不得直接把 TIR 灰度/热强度混入 RGB。
- **补全流**：处理高失效度区域。局部 RGB 编码特征必须完全丢弃；TIR 编码特征经投影后作为该位置特征来源。RGB 不得以残差、skip connection、attention 的 K/V 或任何旁路进入补全流。
- **边界流**：仅处理融合区与补全区的窄边界带，用于连续的颜色、纹理和边缘过渡。补全区内部边界权重为零，因此不存在 RGB 泄漏。

三条流在**特征层**合并为结构 token；不允许生成两张 RGB 结果后再按掩码拼图。

### 2.3 融合区的创新点

不能将融合流写成普通 RGB/TIR 加权融合，也不能将 Deformable Attention 当作独立创新（它本身早已常见）。推荐术语和逻辑：

**TIR 结构引导的可变形 RGB 外观采样与结构渲染。**

TIR 回答“此处真实几何结构/轮廓是什么”；可变形注意力从 RGB 邻域取材，回答“这个轮廓在当前场景里应该呈现怎样的 RGB 颜色、材质和纹理”。连续雾浓度 `M` 只控制结构修正幅度，`r` 只决定是否进入硬补全，二者都不是简单 RGB/TIR 混合比例。

### 2.4 补全区的颜色：TIR 结构检索可靠 RGB 外观记忆

完整替换会带来一个真实问题：TIR 有人的轮廓，但若整图中没有同类 RGB 参考，真实衣服颜色在物理上不可知。论文不能声称恢复唯一真实颜色，只能声称**结构正确、视觉自然的合理 RGB 重建**。

补全区颜色方案已定为：**TIR 结构检索可靠 RGB 外观记忆**。

- 只从低失效度融合区收集“经融合去雾后的 RGB 外观特征”作为记忆 Value；不能用原始有雾 RGB，更不能从补全区拿 RGB。
- 记忆 Key：融合区 TIR 结构 + 全局 TIR 场景上下文。
- 补全区 Query：局部 TIR 结构 + 同一全局 TIR 场景上下文。
- Cross-Attention 输出为 RGB 外观 token。TIR 是查询/结构条件，绝不是颜色 Value，因此不能把检索结果直接与 TIR 灰度特征相加。
- 如果检索置信度低或整图都是浓雾、可靠记忆为空，退化到由全局 TIR 场景特征和局部 TIR 结构条件化的、源域训练得到的 RGB 外观先验；此时只承诺视觉合理，不承诺唯一真实颜色。

### 2.5 唯一最终解码器

最终只有**一个 Transformer 解码器**，不是两条独立解码器，也不是两张区域 RGB 输出：

- 三流合并后的结构 token 是 Query。
- 融合区本地可靠 RGB 外观 token / 补全区检索到的 RGB 外观 token 是 Key–Value。
- 解码器输出唯一 RGB 特征并生成最终去雾图 `J_hat`。

## 3. 源域训练：已确定的监督与训练顺序

源域必须是**一次端到端联合训练**：HDE、单调校准器、融合流、补全流、边界流、外观记忆和最终解码器均持续更新。源域没有 EMA、没有预训练阶段、没有冻结专家；损失权重 warm-up 只是同一次训练内的调度。

### 3.1 在线“实际恢复效用”路由监督

源域没有“完全失效区域”GT，所以不能直接监督补全掩码。路由要从当前模型对两种实际恢复策略的比较中学习。

对每张源域图像，每轮从低/中/高雾浓度分位区间均衡抽取约 4–8 个互不重叠的自适应区域 `Omega`。这些区域不是固定矩形：由源域浓度 GT 与 TIR 强结构边界生成不规则软区域，内部雾情一致，且不跨明显物体边缘。浓度分位只用于保证训练看到各种雾情，**不是**补全阈值。

对每个 `Omega`，使用当前同一个网络、同一组模块、同一个最终解码器，额外做两次仅用于训练的虚拟前向：

1. 在 `Omega` 内强制 `r=0`，区域统一走融合，得到 `J^F`。
2. 在 `Omega` 内强制 `r=1`，区域统一走完整替换，得到 `J^C`。
3. 区域外仍采用当前模型预测的路由。
4. 补全假设中，`Omega` 内 RGB 必须也从可靠外观记忆中排除，防止补全版本偷看该区域 RGB。

“区域整体强制一种策略”是为了让两种恢复拥有相同且完整的局部上下文；但比较完成后必须为区域内的每个像素 `p` 单独生成监督：

`q(p) = sigmoid((e_F(p) - e_C(p)) / T_q)`

其中 `e_X(p)` 是候选恢复 `J^X` 在 `p` 附近、且不超出 `Omega` 的局部误差：颜色/亮度 L1、局部梯度误差、局部 SSIM 误差的加权和。若补全更接近清晰 GT，`q(p)` 接近 1；若融合更好，接近 0。

生成 `q(p)` 时必须 **stop-gradient**。它的含义是“本轮裁判结论固定”；网络不能通过反向传播修改裁判，来伪造一个容易满足的标签。下一轮会用更新后的模型重新比较、重新生成新裁判。

主前向得到 `J_hat, M, r_soft`；虚拟前向只产生冻结的 `q(p)`，不参与梯度更新。路由监督是：

`L_route = mean_{p in Omega} BCE(r_soft(p), q(p))`。

### 3.2 最终去雾损失

所有区域损失作用在**同一张最终输出** `J_hat` 上：

`L_dehaze = lambda_g L_global + lambda_f L_fuse + lambda_p L_comp + lambda_b L_boundary`

- `L_global`：整图重建。
- `L_fuse`：以 `1-r_soft` 为停止梯度区域权重，强调融合区颜色、纹理和结构。
- `L_comp`：以 `r_soft` 为停止梯度区域权重，约束补全区结构正确、外观自然。
- `L_boundary`：以路由梯度生成的边界带为停止梯度权重，约束边界颜色和边缘连续。

停止梯度区域权重的含义：网络不能靠“把难区域改分到另一类”或移动边界来逃避某项区域损失。路由本身仍由 `L_route` 学习。

总源域损失：

`L_src = L_dehaze + lambda_router (lambda_d L_density + lambda_r L_route + lambda_bin L_binary)`

其中 `L_density = SmoothL1(M, M_gt)`，`L_binary = mean(4*r_soft*(1-r_soft))` 后期再逐渐增强。训练开始时 `L_route` 权重从 0 平滑升高，避免基本去雾能力尚未形成时的虚拟比较噪声主导训练。

## 4. 真实域 EMA 适应：已确定方案

源域训练结束后，用源域模型初始化学生和 EMA 教师；网络结构不变。

- 教师不参与梯度更新；仅由 `theta_T <- mu theta_T + (1-mu) theta_S` 更新。
- 对真实 RGB–TIR 对，教师用弱扰动视图，学生用轻微扰动视图。所有几何扰动必须在 RGB/TIR 间同步，输出比较前必须回到同一坐标系。
- 学生与教师要同时保持三项一致：最终去雾 RGB `J`、雾浓度图 `M`、连续路由图 `r_soft`。
- 一致性权重只来自教师跨轻度视图的稳定性；不能把该权重与“RGB 是否失效”的路由混为一谈。
- 真实域不能计算清晰 RGB 重建、`q(p)` 或真实域反事实路由监督。
- 每个真实适应周期混入少量源域批次，继续施加完整 `L_src`，防止 EMA 自训练漂移、遗忘源域去雾和硬替换能力。

总真实适应目标：

`L_adapt = L_real + lambda_anchor L_src`

其中 `L_real = lambda_J L_J + lambda_M L_M + lambda_R L_R`。

## 7. 已踩坑：绝对不要再踩

1. **不要继续使用或构造 `IR_Completion_Mask_GT` 作为正式训练标签。** 用户明确说明源域只有雾浓度图，没有完全失效区域 GT。正式方案必须由融合/补全的实际恢复效用在线产生 q。

2. **不要人工指定“雾浓度超过阈值就补全”。** 允许 `r>=0.5` 做概率硬二值化，但不能把它写成雾浓度阈值；浓度到失效度的关系由单调网络学习。

3. **不要把源域训练说成 EMA、教师学生或分阶段预训练。** EMA 只在真实域适应使用。源域是一次端到端训练，所有模块同时更新。

4. **不要把最终结果做成两张 RGB 图按掩码相加/拼接。** 三流先在特征层合并，最终只有一个解码器、一张 `J_hat`。

5. **不要让补全区 RGB 通过任何路径泄漏。** 包括残差、跳连、注意力 K/V、外观记忆 Value；在“强制补全”的虚拟前向中，整个 `Omega` 都要从 RGB 外观记忆中排除。

6. **不要把 TIR 灰度或热强度当作 RGB 颜色直接注入。** TIR 负责结构/几何与检索条件；颜色、材质、纹理由可靠 RGB 外观记忆或 RGB 外观先验提供。

7. **不要把“可变形注意力”单独包装成创新。** 创新表述是“TIR 结构引导的可变形 RGB 外观采样与结构渲染”；并且数据已经配准，所以不能说它解决跨模态配准误差。

8. **不要主张极浓雾下恢复真实唯一颜色。** 若信息物理上缺失，只能承诺结构正确、视觉自然、语义合理的 RGB 重建。

9. **不要把目标检测写成论文主线。** 它可作为下游验证，但核心主张是去雾质量与可靠跨模态路由。

10. **不要为了保留旧测试而妥协新设计。** 旧测试围绕 mask GT 和输出拼接；应重写测试来验证新不变量。

11. **不要说 TIR 完全不受雾影响。** 使用“相较 RGB 更耐雾、提供互补结构信息”等谨慎表述。

12. **不要让区域权重对路由反向传播。** `r_soft`/边界图作为区域损失权重时必须 detach，否则网络可能通过移动区域逃避损失。

13. **不要让 q 反向传播。** q 是本轮比较裁判，必须 stop-gradient；下一轮重新生成即可。

14. **不要误解 `Omega`。** 虚拟干预以整个不规则局部区域统一融合/补全，保证上下文公平；但 q 和路由监督必须在该区域内逐像素计算，而不是“一块区域一个标签”。

15. **不要在未验证显存前实施全分辨率全局注意力。** 现有测试和注释已经表明 H/4 的 `B x N x N` 注意力可能很大。新注意力应优先采用局部/可变形采样，并在小尺寸 smoke test 后逐步扩大。
