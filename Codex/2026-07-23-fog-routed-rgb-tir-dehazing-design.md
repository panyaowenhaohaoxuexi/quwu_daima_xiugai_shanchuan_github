# 雾浓度路由的 RGB–热红外去雾：方法设计

## 目标与范围

目标任务是配准 RGB–热红外（TIR）图像的可见光去雾。方法面向极浓雾：当局部 RGB 信息已失效时，局部 RGB 编码特征必须被 TIR 编码特征完整替换；当 RGB 仍有可用信息时，采用自适应融合。最终输出始终是清晰 RGB 图像。

热红外在本文中应表述为在目标采集条件下相较 RGB 更耐雾、可提供互补信息，而非完全不受雾影响。

不在当前设计阶段锁定实验消融、检测下游任务或真实域不可用区域人工标注方案。

## 核心研究问题

能否端到端学习由实际恢复效用驱动、受雾浓度约束的近二值区域路由：在同一局部区域中，完整 TIR 替换的恢复结果优于融合时，禁止局部 RGB 特征进入补全流；其余区域自适应融合，从而提升真实极浓雾场景中的可见光去雾质量？

## 核心创新定位

本文的核心不是“雾浓度估计”或“RGB–TIR 自适应融合”，而是**极浓雾失效区的完整 TIR 特征替换（硬补全）**：路由一旦判定该区域的 RGB 已无去雾价值，局部 RGB 编码特征即被完全丢弃，由 TIR 编码特征直接接管。训练中通过同一网络的局部融合/完整替换反事实恢复结果直接学习该决策，雾浓度预测为其提供物理约束；三流处理与真实域 EMA 适应用于让该决策稳定地产生自然、连续的最终 RGB 去雾结果。

## 输入与数据假设

- 源域：合成含雾 RGB、清晰 RGB、配准 TIR、逐像素雾浓度图。
- 真实域：真实含雾 RGB 与配准 TIR；无清晰 RGB 标签。
- RGB 与 TIR 均为像素级配准。

## 架构

### 1. 雾浓度与失效度路由

网络以既有的**雾浓度估计器（HDE）**预测雾浓度图 `M`，再经可学习映射产生连续可见光失效度 `r in [0, 1]`。HDE 从 RGB–TIR 结构差异中区分“真实雾致结构缺失”和“RGB 自身平坦但并非浓雾”的区域；它是可信路由的必要支撑，但本文的主创新仍是由路由触发的完整 TIR 特征替换。

- `r -> 0`：RGB 仍可靠，走融合流。
- `r -> 1`：RGB 已失效，走补全流。

通过近二值约束使 `r` 在训练后趋近 0 或 1，不使用人工设定的浓度阈值。

源域不需要人工补全掩码，也不训练额外候选专家。最终学生模型令 `r = G_phi(M)`，其中 `G_phi` 是可学习、单调不减的浓度—失效度校准器。`L_density` 保持 HDE 输出 `M` 与源域雾浓度标签一致。

为直接得到“融合或完整替换哪一个恢复更好”的监督，在每个源域小批次中，从每张图抽取多个互不重叠的自适应局部区域 `Omega`。每个 `Omega` 不是固定矩形窗口，而是由源域雾浓度真值与 TIR 结构边界确定的、内部雾情一致的不规则软区域；它不跨越明显的浓雾/非浓雾交界或物体结构边界。当前正在训练的同一个源域网络复用**同一套三流和同一个最终解码器**执行两次仅用于训练的虚拟前向：在 `Omega` 内强制 `r=0` 得到融合反事实结果 `J^F`，强制 `r=1` 得到完整替换反事实结果 `J^C`；`Omega` 外保留当前预测路由。补全假设中，`Omega` 内的 RGB 还必须从可靠外观记忆中排除。整个 `Omega` 在每次虚拟前向中必须统一走一种策略，以保证两种恢复方式面对相同的局部上下文；但比较完成后，效用标签按像素计算，而非为整个区域赋一个标签：对每个 `p in Omega`，由 `J^F`、`J^C` 与清晰 RGB `J` 的局部误差形成 `q(p)=sigmoid((e_F(p)-e_C(p))/T_q)`。替换恢复更好时 `q(p)` 接近 1，融合更好时接近 0。构造 `q` 时停止梯度，避免网络通过改变比较标签而投机。

**局部效用的判定。** `Omega` 应是局部窗口而非单像素：单像素无法反映纹理、边缘和解码器的上下文恢复能力。对候选 `X in {F,C}`，在 `Omega` 内的每个像素 `p` 以其局部邻域计算

`e_X(p) = alpha * L1_p(J^X,J) + beta * L_grad,p(J^X,J) + gamma * (1-SSIM_p(J^X,J))`。

其中三项分别评价颜色/亮度、局部结构边缘和局部视觉相似性；`p` 周围的局部邻域限制在 `Omega` 内。这样，`Omega` 只负责提供公平、完整的虚拟恢复上下文，`q(p)` 则保留其中每个像素的细粒度选择差异；完整替换只有在对清晰 RGB 的实际颜色和结构恢复都更有利的像素上，才会得到更高的补全倾向。感知损失可用于最终整图去雾训练，但不用于生成 `q`，因为其感受野过大、不适合作为精确的局部路由裁判。

源域每张图从已知雾浓度图的低、中、高浓度分位区间均衡抽取约 4–8 个互不重叠的自适应区域：低雾区提供“融合更优”的证据，高雾区提供“补全更优”的证据，中间过渡区决定两种策略的切换规律。每轮重新抽取，长期覆盖整图；分位区间只保证裁判能看到各种雾情，不是人为规定何种浓度必须走补全，最终选择仍由 `q` 和可学习单调路由共同决定。

**自适应区域生成。** 对每个随机种子点，在有限局部邻域内构建雾浓度—TIR 结构亲和图：像素与种子雾浓度越接近、从种子到该像素的路径越不跨越 TIR 强结构边缘，其亲和度越高；反之亲和度越低。由该亲和图产生不规则软区域 `Omega`，使一次比较只覆盖“雾情相近且不跨物体边界”的局部内容。浓度相似尺度由种子邻域的局部统计量自适应确定，而非人工指定的补全浓度阈值。该区域仅服务于源域反事实比较与 `q` 的生成，不作为最终补全掩码。

学生的实际输出仍只有一张最终去雾图；其路由由 `L_route=BCE(r_soft,q)` 在各抽样区域内逐像素学习。这样比较的是同一图像、同一局部上下文、同一解码器下两种真实路由选择的恢复效果，而非以雾浓度或人工阈值替代选择依据。

**路由的具体实现。** 对每个像素浓度值 `m=M(p)`，单调校准器先输出路由对数几率 `u=g_phi(m)`，再得到连续路由概率 `r_soft=sigmoid(u/tau)`。`g_phi` 采用所有有效斜率均为非负的单调小网络，例如 `g_phi(m)=b+sum_j softplus(a_j) softplus(softplus(c_j)m+d_j)`；因此网络可以学习浓度—失效度的非线性对应关系，但不会出现“浓度更高、补全倾向反而更低”的反常映射。这里的转折位置和斜率均由数据学习，不人为设定雾浓度阈值。

源域全程仍是一次端到端联合训练：HDE、校准器、融合流、补全流、边界流和解码器均持续参与梯度更新，不冻结、不分阶段训练，也不使用 EMA。训练开始时先令 `L_route` 的权重从零平滑增大，避免网络尚未具备基本去雾能力时产生的早期比较噪声主导训练；这只是同一次训练内的损失权重调度，不是额外预训练阶段。为使离散路由可训练，训练开始时三流使用连续的 `r_soft`；同一次训练内逐步降低温度 `tau`，并在前向传播中采用直通式硬二值化 `r_hard=1[r_soft>=0.5]`。反向传播仍通过 `r_soft` 传递梯度。`0.5` 只是概率的二值化分界，不是人工指定的雾浓度阈值；实际对应到何种浓度完全由 `g_phi` 和实际恢复效用共同学得。`L_binary=mean(4r_soft(1-r_soft))` 仅在后期逐渐增强，用于推动决策清晰化。

### 2. 三流区域处理

- **融合流**：只处理低失效度区域，采用 RGB–TIR 自适应融合。
- **补全流**：只处理高失效度区域。该区域的局部 RGB 编码特征完全丢弃，以经维度投影后的 TIR 特征完整替换。
- **边界校正流**：只处理两种区域的交界带，生成边界校正特征以降低纹理、颜色与边缘突变；不改变两条主流的区域职责。

三流输出在特征层合并，经过同一个合并解码器生成最终清晰 RGB，不采用两张结果图的掩码拼接。

**边界流的具体定义。** 在训练时，以连续路由 `r_soft` 的空间梯度强度生成软边界图 `B=normalize(|partial_x r_soft|+|partial_y r_soft|)`；在推理时，以二值路由的形态梯度生成同等宽度的边界带。边界流只在 `B` 非零的窄带内运行：它读取融合特征、TIR 补全特征和路由边缘，输出校正特征 `H=B*BoundaryBlock(F,C,grad r)`。因此，RGB 相关的融合特征只可在两种区域相接的窄带内帮助颜色和纹理平滑；在补全区内部 `B=0`，边界流为零，局部 RGB 仍完全不能进入。

各尺度先得到受路由约束的融合特征 `F_route` 与仅由 TIR 产生的补全特征 `C_route`，再由可学习合并块生成结构 token `Z^str=Merge(F_route,C_route,H)`。与之配对的外观 token 在融合区来自本地可靠 RGB 外观、在补全区来自可靠外观记忆 Transformer 的检索结果。二者作为同一个最终 Transformer 解码器的双输入：`Z^str` 作 Query，外观 token 作 Key–Value；该解码器只输出一套 RGB 特征并生成一张最终图像，不存在两个解码器、两张区域结果图或掩码拼接。`L_boundary` 只在边界带内对最终输出施加颜色、梯度和边缘连续性约束；计算该项损失的边界权重停止梯度，避免网络靠移动边界来降低损失。

### 3. 外观生成原则

补全区的局部 RGB 不参与特征恢复。其颜色、材质和纹理外观由**TIR 结构检索可靠 RGB 外观记忆**提供：只从低失效度融合区收集经融合去雾特征变换后的外观 token，绝不从补全区收集原始或编码后的 RGB 特征。

具体地，对融合区位置 `j`，以其 TIR 结构和全局 TIR 场景上下文构造记忆键 `K_j`，以其融合后的 RGB 外观特征构造记忆值 `V_j`；可靠记忆掩码为 `stopgrad(1-r_j)`。对补全区位置 `i`，只以本地 TIR 结构和同一全局 TIR 场景上下文构造 Transformer 查询 `Q_i`，并以 `{K_j}`、`{V_j}` 分别作为 Cross-Attention 的键和值，得到 RGB 外观 token `a_i=CrossAttention(Q_i,{K_j},{V_j})`。因此，TIR 决定“到哪里寻找什么结构相似的参考”，可靠融合区提供“该结构可呈现为何种 RGB 外观”。

`a_i` 不与本地 TIR 补全特征直接相加：TIR 特征只保留为结构条件/查询，Cross-Attention 的值及输出均来自可靠 RGB 外观。最终 RGB 解码器以 TIR 结构确定轮廓与空间布局、以 `a_i` 确定颜色、材质和纹理，从两个保持分离的 token 流中生成 RGB 特征，避免把 TIR 灰度或热模式当作颜色混入结果。

检索置信度由注意力分布的集中程度决定：若存在结构和场景均匹配的可靠参考，解码器使用 `a_i` 作为外观来源；若不存在可靠参考，则降低检索外观的影响，转而使用由全局 TIR 场景特征和本地 TIR 结构条件化的训练外观先验。该先验只追求视觉合理，不宣称恢复唯一真实颜色。

当整幅图均为极浓雾时，可靠记忆库为空，模型完全使用上述 TIR 条件化训练先验生成 RGB 外观；此时论文只承诺结构正确、视觉自然的合理 RGB 重建。

### 4. 融合流与补全流的具体特征操作

**融合流：TIR 结构引导的可变形 RGB 外观采样与结构渲染。** 在每个尺度 `l`，RGB 特征先经外观编码器得到 `A_l=E_l^app(V_l)`，保存颜色、材质、明暗与已有纹理；HDE 已提取的多尺度 TIR 差分结构特征 `f_R,l` 经结构投影得到 `S_l=P_l^str(f_R,l)`，只包含轮廓、边缘和形状，不携带热红外强度作为颜色信息。

以 `S_l` 为 Query 和偏移引导、以 `A_l` 为 Key/Value，结构引导的 Deformable Attention 在每条 TIR 轮廓周围自适应采样 RGB 外观支持 `O_l`。它不用于校正 RGB–TIR 配准；其目的只是回答“要把这条 TIR 骨架渲染为可见光细节，应从其 RGB 邻域的哪些颜色、材质和纹理位置取材料”。因此 Attention 的输出 `O_l` 始终是 RGB 外观信息，不是 TIR 灰度或热强度。

网络学习 `K` 个“结构渲染器” `{R_l,k}`，并由 RGB 外观与采样到的外观支持共同产生选择系数 `pi_l,k=softmax(Pi_l([A_l,O_l]))`，形成 RGB 域结构修正：`DeltaA_l=sum_k pi_l,k*R_l,k(S_l,O_l)`。概念上，TIR 提供被渲染的几何骨架，可变形 RGB 采样提供渲染材料，RGB 外观决定该骨架在红车、绿植或灰路面等不同可见光外观中应呈现为哪种边缘和纹理特征；因此 `DeltaA_l` 是可见光特征修正，而不是被直接注入的热红外特征。HDE 内的 TIR 引导可变形卷积用于估计雾浓度；本模块的 Deformable Attention 用于采样 RGB 外观以渲染 TIR 结构，二者职责不同。

HDE 的连续雾浓度 `M_l` 经强度函数 `g_l=G_l^mag(M_l)` 控制修正幅度，得到 `F_route,l=(1-r_l)*ResBlock(A_l+g_l*DeltaA_l)`。这里 `M_l` 只控制“需要补多少 RGB 结构”，`r_l` 只决定“仍融合还是已进入完整替换”，两者均不表示 RGB/TIR 的简单混合比例。

- **补全流的完整替换**：补全特征只由 `C_l=ResBlock(P_l^comp(T_l))` 生成，再用高失效度权重形成 `C_route,l=r_l*C_l`。`V_l` 既不进入 `C_l`，也不作为残差、跳连或注意力键值输入；这正是“完整替换”在实现层面的硬约束。
- **特征合并**：边界校正特征记为 `H_l`，合并特征为 `Z_l=Merge_l([F_route,l,C_route,l,H_l])`。`Merge_l` 是可学习的卷积特征变换，不能退化成按 `r_l` 线性混合两张输出图。

该设计使两条主流在补全前各自独立处理：融合流专门解决“RGB 尚有价值时，如何以 RGB 外观渲染 TIR 结构修正”，补全流专门解决“RGB 已无价值时如何由 TIR 接管局部特征”。

### 5. 可实现的模块接口

令输入的含雾 RGB 和配准 TIR 分别为 `I_V` 与 `I_T`。HDE 按既有设计以 `(I_V,I_T)` 输出 `M` 和多尺度 TIR 差分结构特征 `f_R,l`；去雾主干采用同尺度双编码器，在 `l=1,...,L` 个尺度输出 `V_l = E_V(I_V)` 与 `T_l = E_T(I_T)`。HDE 保持独立的浓度—路由职责，但其 `f_R,l` 被融合流复用为可靠 TIR 几何信息，避免重复提取结构。去雾主干实现时优先从轻量残差 U-Net 编码器起步；编码器类型不是创新点，不需要为“显得复杂”额外堆叠 Transformer。

1. **HDE—路由头**：HDE 以 RGB–TIR 结构差异输出 `M`；单调校准器 `G_phi` 输出连续路由 `r=G_phi(M)`。将 `r` 下采样到各尺度，得到 `r_l`。训练初期允许连续值，随后通过温度退火和近二值损失使其趋向 0/1。
2. **融合流**：TIR 结构引导的 Deformable Attention 在 RGB 邻域采样外观材料，外观自适应结构渲染器据此输出 RGB 域结构修正并形成 `F_l`。只有低失效度位置被送入该流；其任务是保留可靠 RGB 的颜色、纹理，并以 TIR 几何补强 RGB 结构。
3. **硬补全流**：投影块 `P_l^comp(T_l)` 将 TIR 映射到解码特征空间，输出 `C_l`。高失效度位置仅接收 `C_l`；`V_l` 不作为该流的输入、残差或跳连，因而不存在 RGB 残余泄漏。
4. **边界校正流**：由 `r_l` 的可微形态梯度得到窄边界带 `B_l`，并以相邻的 `F_l`、`C_l` 和 `B_l` 为输入生成校正特征 `H_l`。它只处理两区交界处的连续性，不重做融合或补全。
5. **特征合并与解码**：各尺度的三流特征先由可学习合并块变成结构 token `Z_l^str`；融合区本地 RGB 外观与补全区检索 RGB 外观构成外观 token。二者共同送入**同一个**多尺度 Transformer 解码器，其中结构 token 作 Query、外观 token 作 Key–Value，输出唯一的 RGB 特征。这里的合并与解码均为特征变换，不是用 `r` 把两张输出图线性相加。
6. **可靠外观记忆 Transformer**：从融合区的去雾外观特征建立仅含可靠 RGB 信息的键—值记忆库；补全区仅以 TIR 结构形成 Query，通过 Cross-Attention 检索 RGB 外观 token。TIR 特征不与外观 token 直接相加：前者仅提供结构条件，后者才提供颜色和材质，二者在最终 RGB 解码器中保持双流生成。若检索不可信或记忆库为空，则使用 TIR 条件化训练先验；补全区的局部空间特征始终只来自 `C_l`。

因此最终推理链为：

`(I_V,I_T) -> HDE -> M -> r_l -> {融合流, 硬补全流, 边界校正流} -> {Z_l,可靠外观记忆} -> 单一解码器 -> J_hat`，其中三个流同时读取去雾主干的 `(V_l,T_l)`。

源域训练与推理均只保留一个 HDE—校准器—三流—解码器网络。反事实结果仅在源域训练时复用现有三流和同一个最终解码器，不增加候选专家、EMA 教师、额外解码器或分流辅助输出头。EMA 仅在后续真实域适应阶段使用。

## 训练

### 阶段一：源域监督

训练所有模块：浓度预测、失效度路由、融合流、补全流、边界流与合并解码器。

源域总损失采用“去雾损失 + 路由监督损失”结构：

`L_src = L_dehaze + lambda_router * L_router`

其中：

`L_dehaze = lambda_g L_global + lambda_f L_fuse + lambda_p L_comp + lambda_b L_boundary`

令最终输出为 `J_hat`、清晰 RGB 为 `J`，并定义逐像素重建项 `d_rec(J_hat,J)=a_1*|J_hat-J|+a_2*(1-SSIM_local(J_hat,J))+a_3*|grad J_hat-grad J|`。以停止梯度的路由权重 `R=stopgrad(r_soft)` 和边界权重 `B=stopgrad(Boundary(r_soft))` 划分区域，则：

- `L_global = mean(d_rec)`：对整幅最终去雾图的整体重建约束。
- `L_fuse = normalized_sum((1-R)*d_rec)`：只强调融合区的颜色、纹理和结构恢复。
- `L_comp = normalized_sum(R*d_rec)`：只约束完整替换后形成结构正确、视觉自然的合理外观。
- `L_boundary = normalized_sum(B*(a_4*|J_hat-J|+a_5*|grad J_hat-grad J|))`：只在边界带约束颜色和边缘连续。

`R` 与 `B` 只作为区域损失的计分权重、且停止梯度，网络不能仅靠移动路由或边界来逃避某一项区域损失。路由本身由后述的实际恢复效用监督学习；所有四项去雾损失始终作用于同一个 `J_hat`。

`L_router = lambda_d L_density + lambda_r L_route + lambda_bin L_binary`

- `L_density = SmoothL1(M,M_gt)`：约束 HDE 浓度图与源域标签一致。
- `L_route = mean_{p in Omega}(BCE(r_soft(p),q(p)))`：仅在抽样区域内逐像素令当前路由与在线比较得到的“融合/完整替换实际恢复效用”标签一致。
- `L_binary = mean(4*r_soft*(1-r_soft))`：推动路由从连续值趋近明确的融合/补全决策；其权重在训练后段逐渐增强。

所有损失均在同一次端到端源域训练内计算；不存在分流辅助输出头或区域结果图。

### 阶段二：真实域 EMA 适应

网络结构不变。以源域训练完成的网络初始化学生和教师；学生网络在真实 RGB–TIR 对上继续更新，教师网络不参与梯度更新，其参数仅由 `theta_teacher <- mu*theta_teacher+(1-mu)*theta_student` 更新。

对同一真实样本构造教师弱增强视图与学生轻度扰动视图。所有几何变换必须在 RGB 与 TIR 间同步；比较教师与学生输出前，将其映射回同一空间坐标。避免使用会改变目标清晰 RGB 色彩语义的独立强颜色扰动。

教师产生 `J_T, M_T, r_T_soft`，学生产生 `J_S, M_S, r_S_soft`。真实域一致性定义为：

`L_real = lambda_J*L_J + lambda_M*L_M + lambda_R*L_R`

- `L_J = weighted_L1(J_S, stopgrad(J_T))`：最终去雾 RGB 一致性；
- `L_M = weighted_L1(M_S, stopgrad(M_T))`：HDE 雾浓度图一致性；
- `L_R = weighted_BCE(r_S_soft, stopgrad(r_T_soft))`：连续路由图一致性。

权重只来自教师预测的跨视图稳定性：教师在两种轻度视图下越一致，该位置权重越高；它只决定何处更可信地施加一致性，不能与“RGB 是否失效”的路由 `r` 混同。真实域不计算清晰 RGB 重建损失、局部反事实效用标签或源域的 `L_route`。

为避免教师—学生共同漂移，真实适应的每个训练周期混入少量源域批次，并继续施加完整的 `L_src`。因此学生优化目标为 `L_adapt = L_real + lambda_anchor*L_src`；教师始终无梯度，EMA 只在真实域适应阶段使用。

## 文献定位风险

- 公开 RGB–IR 去雾已有可靠性加权融合思路，因而本文不能把“自适应融合”或“雾浓度引导融合”单独作为创新点。
- ACM MM 2025 的 HDCFN 已基于预测雾分布图调整 RGB/TIR 连续融合权重；该方法是关键强基线。本文须明确区分：HDCFN 不执行局部 RGB 特征的完整 TIR 替换，也没有以同一局部上下文内“融合/替换的实际恢复效用”监督近二值路由。
- 已有 RGB–FIR 融合—迁移去雾以及单模态 EMA 一致性去雾适应。因此本文的主张必须聚焦于：实际恢复效用驱动、受雾浓度约束的端到端近二值完整替换路由，以及融合/补全/边界三流与跨域多输出一致性的联动。
- 关键对比文献待实验阶段逐篇核对其数据模态、是否公开代码及训练协议。
