Replace structure-energy prior with haze-density prior — Plan
Context
The current IR-VIS structure energy contrast approach (Sobel on both images, joint normalization, E_diff) has two weaknesses:

1. E_diff = E_ir - E_vis can be noisy when both IR and VIS are low-texture (e.g., flat sky). False positives.
2. Requires computing structure energy on IR, which is an indirect proxy. Haze is a property of the VIS image.
The new approach derives haze density directly from VIS physical cues (brightness, saturation, local contrast), using IR structure only as a spatial calibration signal to suppress sky false positives.
Files to modify
1. `model/Teacher.py` — 4 edit sites
A) Lines 22-57 — Delete `compute_raw_structure_energy` + `compute_structure_energy_pair`. Add two new functions:

* `compute_haze_density(x_vis_01)`: Brightness × (1-Saturation) × (1-local_contrast) → per-image min-max normalize → (B,1,H,W). High value = dense haze.
* `compute_ir_structure(x_ir)`: Sobel gradient energy → Gaussian smooth → per-image min-max normalize → (B,1,H,W). Same core as old `compute_raw_structure_energy` but with normalization appended.
B) Line ~1055 — `q_vis_refine` input channels: 7 → 5
C) Lines 1207-1217 — Replace HAPM block:

```python
H = compute_haze_density(x_vis_01)
E_ir = compute_ir_structure(x_ir)
vis_input = torch.cat([H, E_ir, x_vis_01], dim=1)  # 5ch
```
